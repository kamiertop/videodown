# 原生界面

运行：`CGO_ENABLED=0 go run .`。

## 目录与职责

```text
main.go                    原生入口、共享数据库初始化、服务组装与退出清理
internal/gui/
  shell.go                 窗口创建、圆角框架与状态持有
  titlebar.go              居中品牌、左侧导航、右侧 GitHub/窗口控制
  tray.go                  托盘菜单和窗口恢复
  close.go                 关闭/退出事件、选择弹窗、记住选择
  closing/                 与窗口 API 无关的关闭决策
  settings.go              异步配置写入、文件选择和 FFmpeg 检测
  jobs.go                  公共后台任务调度与退出等待
  guiruntime/              页面共用的后台任务与文件操作接口
  imagecache/              图片请求、解码与有容量限制的缓存
  preferences/             结构化配置的表单适配与有类型的变更项
  theme.go                 主题名称与原生颜色映射
  style/tokens.go          原生字号、字重、圆角、边框、间距与常用尺寸
  content.go               路由组装与每页滚动
  assets/                  图标的嵌入、解析与共用标识
  navigation/              路由与页面定义
  components/              共享按钮、菜单、设置开关和辅助文本
  pages/
    state.go               组装各页面状态和分发路由
    home/                  两个平台图标入口
    settings/              设置布局、表单状态和六个分类页面
    bilibili/              独立侧栏布局、下载、UP 主、动态、收藏/合集、历史及账号视图
    douyin/                抖音页面入口及独立状态
```

平台业务分别位于 `pages/bilibili/` 与 `pages/douyin/`；共用控件放入 `components/`，通用样式放入 `style/`。设置表单及相关状态集中在 `pages/settings/`，不依赖具体平台页面。

哔哩哔哩使用 88 DIP 左侧导航栏与右侧独立滚动内容，账号入口固定在侧栏底部。菜单区域可独立滚动，最小窗口仍保留左右布局。收藏夹/合集标签、每页搜索、链接输入和滚动位置在切换后保留；子路由使用嵌套淡入切换，避免重复绑定侧栏的滚动句柄。账号、关注、UP 主投稿与合集/系列、收藏夹及订阅合集已直接使用 Go API 和返回的 model。支持二维码生成与轮询、凭证复用与刷新、个人资料与退出登录、分页、搜索、视频选择及添加到待下载列表。动态、播放历史、下载历史、手动视频解析及实际下载队列均已接入。页面采用圆角边框与圆角按钮，不显示介绍段落；下载页空列表时仅保留输入栏，UP 主与历史页采用紧凑工具栏，收藏页以标签和左右分栏组织内容。

页面不持有窗口或路由器；导航和平台操作通过回调请求。共用资源只解析一次。首页只显示两个居中的平台图标；品牌居中，页面导航在标题栏左侧，GitHub 和窗口控制在右侧，无全局左侧菜单和底部状态栏。

各平台仅在首次进入对应路由时初始化；停留首页或设置页不会触发平台登录检查。切换回来复用已加载状态，账号页仍可手动刷新。

## 配置与退出

应用配置和 Cookie 存储在结构化的 `config.toml` 中，下载历史使用 SQLite 的 `history.sqlite`，都位于可执行文件所在文件夹。首次启动自动生成缺失文件，已有配置不覆盖；默认相对下载目录 `./download` 按配置所在文件夹解析。`go run` 使用当前工作目录。可用 `-data-dir` 指定其他位置。图标既内嵌在二进制中，也会随便携发行文件夹提供。配置结构见根目录的 `config.example.toml`。

代码通过 `store.Config()` 获取有类型的快照，通过 `store.UpdateConfig` 校验并原子提交修改。SQLite 仅保存下载历史，使用 sqlx 和无 CGO 的 SQLite 驱动。

关闭行为：

- 没有 `app.close_to_tray` 配置时弹窗询问，支持取消或“记住选择”。
- 保存为 `true` 时隐藏到托盘；保存为 `false` 时退出。
- 托盘不可用时不隐藏；存在下载任务时先确认退出。
- 托盘菜单的“退出”绕过窗口关闭偏好，但有任务时仍确认。
- 配置保存失败会显示错误，不执行本次关闭动作；退出等待配置写入完成。

通用、哔哩哔哩、下载、命名模板、FFmpeg 和关于采用左侧分类、右侧独立滚动布局，设置侧栏宽度为 176 DIP，内容宽度和卡片顺序一致；宽度小于 768 时，分类栏切换到顶部横向导航。目录、主题、更新偏好、并发数、随机休眠、增量下载、命名模板和目录分组会保存到共享配置。模板及分组一起提交，滑块连续编辑会合并保存；保存失败恢复原值。

目录选择与 FFmpeg 浏览使用原生对话框；FFmpeg 检测在后台执行并设有超时。启动时按自动更新偏好在独立后台作业中检查版本，支持取消与超时；发现新版本时显示版本号和发布说明，并提供发布页入口。开发版显示正式版本提示，网络错误不打断使用。`Options.ActiveDownloads` 提供进行中任务探针，原生下载队列已接入，同时统计排队中的批量任务。

## 验证

```sh
CGO_ENABLED=0 go test ./internal/gui/... ./bilibili/api ./internal/storage ./utils
go test -race ./bilibili/api ./internal/gui/pages/bilibili
CGO_ENABLED=0 go tool mygo vet .
```

UP 主详情使用 `/bilibili/up/{mid}` 路由，标题栏回退/前进和详情右上角的返回按钮可在关注列表与详情之间切换，保留关注页码、输入和每条路由的滚动状态。详情展示作者资料、投稿及合集/系列列表，支持选择已加载的视频加入待下载列表，或创建一键下载全部的独立批量任务。常用字号、圆角和尺寸集中在 `style/tokens.go`；普通按钮由 `components/button.go` 统一设置圆角与字号，字体通过 `style.Font` 应用系统文字缩放。

下载服务通过原生进度监听器更新界面。API 作业按提交顺序在后台执行，完成后通过 `Window.Update` 发布；图片采用独立并发池。请求使用代次检查丢弃旧结果，离开页面停止二维码轮询，退出等待后台作业后再关闭数据库。一键下载会跳转到下载页并生成可折叠卡片，按顺序逐页执行，支持停止、继续、重试与增量跳过。休眠阶段展示倒计时和动画；普通选择的视频保留独立的画质及音质选项。

测试使用模拟 API/HTTP 响应，覆盖二维码确认、过期与取消、共享凭证保存/清理、作者和视频分页、重试、旧请求隔离、选择及批量添加。真实扫码与远端接口需要联网后使用手机确认。

其他测试覆盖布局、路由、输入保留、共享配置读取/保存、重启恢复、连续编辑写入、首次关闭弹窗、记住选择、退出决策与保存失败。截图使用无窗口渲染。全仓库支持 `CGO_ENABLED=0 go test ./...`。

Linux 真实桌面退出回归（会短暂显示窗口，需要桌面会话和 AppIndicator）：

```sh
VIDEODOWN_GUI_LIFECYCLE=1 go test ./internal/gui -run '^TestNativeQuit$' -v -count=1
```

该测试验证已保存的退出选择、显式退出，以及收起到托盘后再退出时子进程确实结束。文件选择与真实托盘菜单仍需手动验证。

## 抖音原生页面

抖音使用同一套 Go/MyGo 布局、公共按钮与字体尺寸，直接展示 API 返回的 model。账号页可保存、验证或清除 Cookie；凭证写入 `config.toml`，切换账号会清空旧账号的页面与待下载数据，有任务时禁止更换凭证。

已接入关注用户、用户作品与合集、收藏视频、收藏夹、收藏的合集、关注动态、播放历史，以及 SQLite 下载历史。卡片点击选择，作者名独立导航，作品列表滚动到底部自动分页；收藏夹与合集有独立路由，可使用标题栏前进和后退。

选中的作品先进入下载页，支持选择画质、保存封面、下载视频和图集（包括 Live Photo 素材和配乐）。一键下载全部创建独立可折叠分组，组间排队、组内按公共并发设置执行，支持停止、继续、失败重试；全部成功后自动关闭分组。下载进度和休眠倒计时通过 UI 线程更新。新鲜的播放地址直接复用，过期或列表缺少地址时才在任务开始前补取详情。

抖音 API 和下载服务独立于界面运行时。验证命令：

```sh
CGO_ENABLED=0 go test ./internal/gui/... ./douyin/... ./internal/storage/... ./utils/...
CGO_ENABLED=0 go tool mygo vet ./internal/gui
```

测试使用本地模拟响应，不调用抖音远端；Cookie 有效性与平台风控结果需在真实账号下验证。
